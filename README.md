# Spongyabob Marathon 🍍

## A projektről

A projekt egy Spongyabob-tematikájú esemény weboldala, amely egy közös, 6 órás Spongyabob-nézést mutat be. Az esemény szombaton kerül megrendezésre.

Az oldal HTML, CSS és Bootstrap 5 felhasználásával készül.

## Felhasznált technológiák

- HTML5
- CSS3
- Bootstrap 5.3.8

## Mappaszerkezet

```text
mini-projekt/
├── index.html
├── css/
│   └── style.css
└── img/
    └── bg.png
```

## Megvalósított funkciók

- Középre igazított fejléc.
- Az esemény címe és rövid leírása.
- Bootstrap segítségével kialakított navigációs gombok.
- Egyéni háttérkép és színátmenetes sötétítés.
- Átlátható, továbbfejleszthető HTML-struktúra.

## Megjelenés

Az oldal hátterét az `img/bg.png` kép és egy rózsaszínes-fekete színátmenet alkotja. A fejléc sötét, áttetsző hátteret kapott, a szövegek pedig fehér színűek.

## Futtatás

1. Töltsd le vagy klónozd a projektet.
2. Nyisd meg a `mini-projekt` mappát.
3. Nyisd meg az `index.html` fájlt egy böngészőben.

A Bootstrap stílusainak betöltéséhez internetkapcsolat szükséges.
